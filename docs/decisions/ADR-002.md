## Context

SRS Sec 3.1 and 3.2 list **"Recharts (or Chart.js)"** for the administrator analytics dashboards.
The administrator dashboard must show (FR-ADM-05 [S]):
- Totals (users, NGOs, donations, completed hand-overs)
- Fulfilment rate
- Category distribution (likely a pie/doughnut chart)
- Monthly trend charts (likely a line/bar chart)

It must work in the specified browsers (NFR-CMP-01 [M]).

---

## Options

### Option A — Recharts

| Criterion | Assessment |
|-----------|-----------|
| **Effort** | Low-medium. Built specifically for React; declarative JSX components (`<LineChart>`, `<PieChart>`). Fits perfectly with the React component mental model. |
| **Risk** | Low. Very stable and widely used in React SPAs. Relies on D3 underneath, rendering SVG. |
| **NFR-CMP-01 fit** | Full. SVG is perfectly supported in all target browsers. |
| **NFR-SEC-01 / CSP** | No violation when installed via npm. |
| **FR-ADM-05** | Fully supports the required chart types. |
| **SRS constraints violated** | None identified. |

### Option B — Chart.js (with react-chartjs-2)

| Criterion | Assessment |
|-----------|-----------|
| **Effort** | Medium. Chart.js is vanilla JS; requires the `react-chartjs-2` wrapper for clean React integration. Configuration is object-based rather than JSX-declarative, which is slightly more verbose. |
| **Risk** | Low. The most popular charting library globally. Renders to HTML5 `<canvas>` rather than SVG. |
| **NFR-CMP-01 fit** | Full. Canvas is supported in all target browsers. |
| **NFR-SEC-01 / CSP** | No violation when installed via npm. |
| **FR-ADM-05** | Fully supports the required chart types. |
| **SRS constraints violated** | None identified. |
