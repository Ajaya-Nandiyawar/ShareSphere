## Context

SRS Sec 3.1 and 3.2 list **"Fetch API / Axios"** as a single undecided entry (SRS Sec 3.1, version column "–").
The SPA must:

- Send `credentials: "include"` so the `PHPSESSID` session cookie travels with every request (SRS Sec 3.2).
- Add the `X-CSRF-Token` header on every state-changing request (FR-METH-03 [M]).
- Handle 401 / 403 / 422 uniformly (SRS Sec 3.2).
- Operate within a **`Content-Security-Policy: script-src 'self'`** (SRS Sec 12.2 / NFR-SEC-01) — no CDN scripts.
- Run on the latest two versions of Chrome, Edge, Firefox, Safari and on Android/iOS browsers (NFR-CMP-01 [M]).

The Vite proxy keeps SPA and API same-origin in development (SRS Sec 3.2, 3.6); in production a reverse proxy does the same.

## Options

### Option A — Fetch API (browser built-in)

| Criterion | Assessment |
|-----------|-----------|
| **Effort** | Low — no install, no bundle size. A thin `api.js` wrapper provides the interceptor pattern (credentials, CSRF header, error normalisation). ~50–80 LoC. |
| **Risk** | Low-medium — streaming and abort handling are slightly more verbose than Axios. No third-party dependency to audit or update. |
| **NFR-CMP-01 fit** | Full — Fetch is native in all SRS-listed browser versions (Chrome/Edge 115+, Firefox 115+, Safari 17+). No polyfill needed. |
| **NFR-SEC-01 / CSP** | No violation — no external script. |
| **FR-METH-03** | Implementable via a wrapper function that always adds the `X-CSRF-Token` header. |
| **Same-origin cookies** | Supported via `credentials: "include"` and `SameSite=Strict` (SRS Sec 3.2, 3.5). |
| **Windows XAMPP dev** | No impact — browser feature, not Node.js runtime. |
| **SRS constraints violated** | None identified. |

### Option B — Axios (third-party library)

| Criterion | Assessment |
|-----------|-----------|
| **Effort** | Low — `npm install axios`. Interceptors are a first-class API: one `request` interceptor adds credentials and CSRF header; one `response` interceptor normalises errors. ~30–50 LoC interceptor, less boilerplate than Option A. |
| **Risk** | Low — mature library (v1.x), widely used, good TypeScript types. Introduces one npm dependency to audit (CVE watch). Bundle size ~13 kB gzipped. |
| **NFR-CMP-01 fit** | Full — Axios v1 targets the same browser range. |
| **NFR-SEC-01 / CSP** | No violation if installed via npm and bundled by Vite (not loaded from CDN). |
| **FR-METH-03** | Interceptors make CSRF injection straightforward. |
| **Same-origin cookies** | `withCredentials: true` on the Axios instance is the equivalent of `credentials: "include"`. |
| **Windows XAMPP dev** | No impact. |
| **SRS constraints violated** | None identified — **provided** Axios is bundled via npm/Vite, not loaded from an external URL (which would violate `script-src 'self'`, NFR-SEC-01). If a CDN link were used that would violate NFR-SEC-01. |

## SRS Constraints That Would Be Violated by Each Option

| Option | Potential Violation | Condition |
|--------|--------------------|-----------:|
| Option A | None | — |
| Option B | **NFR-SEC-01** (`script-src 'self'`) | Only if Axios is loaded via CDN `<script>` tag instead of npm bundle. Bundling via Vite avoids this. |
